# Test Specifications

Plain-English specification of every automated test in the Rentlet repository, written as Given / When / Then.

**How to read this document**

- There is one section per source file under test, with its relative path. Each section's table has one row per test (`it` / `test`), grouped by its `describe` block.
- **Given** is the starting data or setup, **When** is the action or call being made, and **Then** is what the test requires to be true afterwards.
- This repository has no React component tests. All 24 test files are Vitest unit tests of plain TypeScript logic: the Firebase Cloud Functions in `functions/src` and the page-logic modules in `src`. For those tests, "Component mounts / renders" does not apply; **When** always names the function being called or the event being simulated.
- One `it.each` block in `functions/src/notify.test.ts` runs 11 scenarios. Each scenario is listed as its own row, so the table has more rows than that file has `it` blocks.
- "Standard chat setup", "Shared setup" and similar notes above a table describe data reused by several rows in that table.
